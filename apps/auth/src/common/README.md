# Common / Shared Utilities (`src/common/`)

Общие утилиты, константы, кастомные ошибки и хелперы, используемые в разных слоях сервиса.

## Структура
- `errors/` — классы ошибок приложения (`AppError`, `NotFoundError`, `UnauthorizedError` и т.д.).
- `constants/` — константы (списки стандартных scopes, роли, имена кук).
- `utils/` — чистые вспомогательные функции (форматирование, хелперы дат, генераторы токенов/строк).
- `types/` — глобальные TypeScript типы, интерфейсы и расширения типов (например, `express.d.ts`).
