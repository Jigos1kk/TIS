# Controllers (`src/controllers/`)

Слой контроллеров Express для обработки HTTP-запросов и формирования HTTP-ответов.

## Содержимое
- `interaction.controller.ts` — обработка OIDC interaction шагов: рендеринг формы логина, приём данных аутентификации, завершение interaction через `oidc.interactionFinished()`.
- `auth.controller.ts` — вспомогательные операции авторизации/регистрации (если вынесены отдельно).
- `user.controller.ts` — контроллеры управления профилем пользователя.

## Правила
- Контроллеры не содержат сложной бизнес-логики и прямых SQL-запросов.
- Вызывают методы сервисов (`src/services/`), валидируют входящие данные и возвращают HTTP-ответ.
