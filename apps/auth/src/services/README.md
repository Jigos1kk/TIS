# Services (`src/services/`)

Слой бизнес-логики приложения.

## Содержимое
- `user.service.ts` — создание, поиск, верификация паролей пользователей (хеширование argon2/bcrypt).
- `auth.service.ts` — логика аутентификации, сессий, блокировок, проверок безопасности.
- `interaction.service.ts` — логика резолвинга взаимодействия с `oidc-provider` (логин, consent/scopes, claims).
- `client.service.ts` — управление зарегистрированными OIDC клиентами.

## Правила
- Сервисы не зависят от объектов Express (`req`, `res`).
- Принимают чистые DTO/параметры, возвращают данные или выбрасывают доменные ошибки.
