# Providers (`src/providers/`)

Слой провайдеров интеграций и криптографических ключей.

## Содержимое
- Загрузка и инициализация криптографических ключей (JWKS для подписи токенов, ключи ротации cookie).
- Внешние провайдеры аутентификации (Social logins: Google, GitHub и т.д. при расширении).
- Фабрики/инициализаторы сторонних сервисов.
