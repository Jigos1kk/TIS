# Config (`src/config/`)

Содержит конфигурационные файлы приложения, парсинг и валидацию переменных окружения.

## Содержимое
- `env.ts` — чтение и строгая типизация переменных окружения (через `dotenv`), дефолтные значения.
- Конфигурации для различных подсистем (OIDC, TypeORM, Cookie, CORS).

## Правила
- Доступ к `process.env` разрешён **только** внутри этой директории.
- Экспортируются валидированные, типизированные объекты конфигурации.
