# Database (`src/database/`)

Слой работы с базой данных (PostgreSQL) с использованием TypeORM.

## Структура
- `entity/` — TypeORM сущности (таблицы БД: пользователи, клиенты, гранты, токены и т.д.).
- `repository/` — кастомные репозитории и методы прямого доступа к данным.
- `migrations/` — файлы миграций базы данных.
- `data-source.ts` / `index.ts` — инициализация `DataSource` TypeORM, подключение к пулу соединений.

## Правила
- Бизнес-логика здесь не реализуется.
- Вся работа с базой ведётся через типизированные сущности и репозитории.
